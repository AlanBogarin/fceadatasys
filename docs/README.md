## Convenciones

AGENTS.md conserva su prioridad como contrato maestro. Los documentos académicos se mantienen en Word y la defensa en PowerPoint. No se guardan ZIP de entrega ni PDF equivalentes a esos editables. Los PDF de referencia, reportes, cronograma y datos de demostración tienen su propia función. Cada documento tiene una fuente editable; los antecedentes se identifican como historia. Al mover una guía se actualizan sus enlaces y las referencias de entrada.
